使用说明与常见问题
  • 安装：Chrome / Edge 打开 chrome://extensions（Edge 为 edge://extensions）→ 开启「开发者模式」→ 「加载已解压的扩展程序」→ 选中本文件夹。之后点工具栏图标即可打开。
  • 配套桌面程序：先运行包体里的 ImageGrabber.exe 并保持窗口打开，在这里点「发送到桌面程序」，图片就由桌面程序写进它设置的本地文件夹（真实绝对路径）。需要登录、JS 渲染、懒加载的网页走这条路最省事。
  • 抓取范围：<img>、srcset / picture、懒加载 data-* 属性、CSS 背景图与伪元素、Shadow DOM、同源 iframe、页面源码与 JSON 里的图片地址、内联 base64 图、blob 图、以及网络层所有 image/* 响应。格式不靠白名单，JPG/PNG/WebP/AVIF/GIF/SVG/BMP/ICO/APNG/JXL/HEIC 与无扩展名的动态图片都能收。
  • 图片很多或抓不全：用「刷新并完整抓取」，并确认「自动滚动触发懒加载」已勾选。滚动只影响目标页面，结束后会滚回顶部。
  • 部分站点有防盗链：优先在目标页面上下文取图（自动带 Cookie 和 Referer），失败会自动改用扩展请求，再失败会记在日志里。
  • blob: 与 data: 图片只能在「直接写入指定文件夹」模式保存，「浏览器默认下载目录」模式会跳过它们。
  • Firefox 不支持「选择文件夹」，请改用「浏览器默认下载目录」模式。
  • 请遵守目标网站的条款与 robots 规则，商用前确认图片版权授权。
